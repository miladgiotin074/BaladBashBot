# بلد باش 🧠

ربات تلگرام چالش اطلاعات عمومی با مینی‌اپ (Telegram Mini App).

## امکانات

- ⚔️ **دوئل نوبتی**: ۵ دور × ۳ سوال، انتخاب موضوع به نوبت، حریف شانسی یا دعوت دوست
- 🤖 **حریف تمرینی**: اگر حریف واقعی پیدا نشود ربات وارد بازی می‌شود (با نشان 🤖)
- 📅 **چالش روزانه**: ۱۰ سوال یکسان برای همه + رده‌بندی روز
- 🛡️ **حالت بقا**: ۳ جان، سوال‌های کم‌کم سخت‌تر، رکورد
- 🧰 **کمک‌ها**: حذف دو گزینه، زمان بیشتر، نظر بقیه
- 🏆 رده‌بندی کلی و هفتگی، سطح و لقب، ۲۰ مدال، جایزهٔ روزانه، دعوت دوستان
- ✍️ **سوال‌ساز** + پنل مدیریت برای تأیید/رد سوال‌ها و گزارش‌ها
- 🛍️ فروشگاه سکه با Telegram Stars (اختیاری)
- 🔔 اعلان نوبت و نتیجه از طریق ربات
- بانک اولیهٔ ۳۰۱ سوال فارسی در ۱۰ موضوع (`server/data/questions/*.json`)

## پیش‌نیاز

روی سرور لینوکس از قبل چیزی لازم نیست. `bash run.sh` ابزارهای پایه و Node.js نسخهٔ ۲۲ را نصب می‌کند. دیتابیس SQLite داخلی خودِ Node است.

## راه‌اندازی

روی سرور لینوکس، بعد از کلون، همین یک دستور کافی است. پیش‌نیازها را نصب می‌کند و توکن، دامنه، پورت، ادمین‌ها و بقیهٔ تنظیمات را همان‌جا می‌پرسد و در `.env` ذخیره می‌کند:

```bash
bash run.sh
```

دفعهٔ بعد همان دستور سرور را بالا می‌آورد. برای عوض کردن تنظیمات: `bash run.sh --config`

اگر بخواهید مرحله‌به‌مرحله جلو بروید:

```bash
npm install
```

```bash
npm run build
```

```bash
npm start
```

۱. در [@BotFather](https://t.me/BotFather) ربات بسازید و توکن را بگیرید.
۲. `bash run.sh` توکن، دامنهٔ **HTTPS**، پورت و `ADMIN_IDS` را می‌پرسد و در `.env` می‌نویسد.
۳. **`DEV_AUTH=false`** بگذارید (فقط برای تست محلی true باشد).
۴. برای HTTPS می‌توانید از دامنه + reverse proxy یا تونل (مثلاً cloudflared) استفاده کنید.
۵. اگر سرور به api.telegram.org دسترسی ندارد، `PROXY_URL` را تنظیم کنید.
۶. (اختیاری) در BotFather برای ربات Main Mini App تنظیم کنید و `MAIN_MINIAPP=true` بگذارید تا لینک‌های دعوت مستقیم مینی‌اپ را باز کنند.

## تست محلی بدون تلگرام

با `DEV_AUTH=true` سرور را اجرا و این آدرس را باز کنید: `http://localhost:3000/?dev=1&name=Ali`
(عدد `dev` شناسهٔ کاربر آزمایشی است؛ با دو عدد مختلف در دو تب می‌توانید دوئل دونفره را امتحان کنید.)

## توسعه

```bash
npm run dev
```

سرور روی پورت ۳۰۰۰ و Vite روی ۵۱۷۳ بالا می‌آید. بررسی تایپ‌ها: `npm run typecheck`

## ساختار

- `server/` — سرور Express، ربات grammY، منطق بازی (`server/game/`)
- `web/` — مینی‌اپ React
- `shared/` — ثابت‌ها و تایپ‌های مشترک (قوانین، جایزه‌ها، قیمت‌ها در `shared/constants.ts`)
- `data/` — فایل دیتابیس (خودکار ساخته می‌شود)

## افزودن سوال

به فایل‌های `server/data/questions/<موضوع>.json` ردیف اضافه کنید:
`["متن سوال", "پاسخ درست", "غلط ۱", "غلط ۲", "غلط ۳", سختی ۱ تا ۳]` — با اجرای دوبارهٔ سرور، سوال‌های جدید وارد می‌شوند.
